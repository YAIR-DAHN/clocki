# 🕒 קלוקי - שעון מעורר חכם

<div dir="rtl">

קלוקי הוא שעון מעורר חכם וידידותי המציע מגוון אפשרויות לכיבוי ההתראה, במטרה לוודא שאכן התעוררתם!

## ✨ תכונות עיקריות

### 🔔 מגוון אפשרויות להתראה
- **התראה קלאסית** - כיבוי או נודניק בלחיצת כפתור
- **הקלדת טקסט** - ההתראה תמשיך לצלצל עד שתקלידו את הטקסט שהגדרתם מראש
- **משחק נחש (Snake)** - עליכם להשיג ניקוד מסוים במשחק כדי לכבות את ההתראה
- **תרגילי חשבון (בפיתוח)** - עליכם לפתור מספר תרגילים ברמה שבחרתם לכבות את ההתראה

### ⚙️ התאמה אישית
- הגדרת זמני התראה מרובים
- בחירת סוג ההתראה לכל שעון בנפרד
- אפשרות לעריכת התראות קיימות

## 🚀 התקנה והרצה

### דרישות מקדימות
- Flutter SDK
- Android Studio / VS Code
- Git

### שלבי ההתקנה

1. שכפול המאגר:

```
git clone https://github.com/YAIR-DAHN/clocki
```

2. התקנת הספריות הנדרשות:

```
flutter pub get
```

3. הרצת האפליקציה:

```
flutter run
```
